# delfuria/homebrew-tap

Homebrew casks by Stefano Del Furia.

```sh
brew tap delfuria/tap
brew install --cask battery-toolkit-next
```

| Cask | Description |
| --- | --- |
| `battery-toolkit-next` | [Battery Toolkit Next](https://github.com/delfuria/Battery-Toolkit-Next) — control the platform power state of Apple Silicon Macs |
